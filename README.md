# Delete Git Branch Locally and Remotely

This repository is a demonstration for the article "[Delete Git Branch Locally and Remotely](https://metaschool.so/articles/delete-git-branch)". It provides step-by-step instructions on how to safely delete a Git branch both locally and remotely.

## 📝 Purpose

The repository contains no functional code, as it's used solely for the purpose of demonstrating Git branch deletion. The article explains the following:

- How to delete a Git branch **locally** using `git branch -d` or `git branch -D`
- How to delete a Git branch **remotely** using `git push --delete`
- Best practices and tips to ensure safe branch removal

## 🚀 Steps Covered in the Article

1. **Deleting a Local Branch**  
   - Command: `git branch -d <branch_name>`
   
2. **Force Deleting a Local Branch**  
   - Command: `git branch -D <branch_name>`
   
3. **Deleting a Remote Branch**  
   - Command: `git push origin --delete <branch_name>`
   
4. **Pruning Stale Remote References**  
   - Command: `git fetch -p`

**Note:** This is a **blank repository** for demonstration purposes only. To learn the proper steps to delete Git branches, read the full article [here](https://metaschool.so/articles/delete-git-branch).
